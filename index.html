Complete Network Configuration from Start to Finish

This project involved the complete design, configuration, and deployment of a network infrastructure for a medium-sized organization. I managed every aspect of the network setup, from physical hardware installation to advanced configuration of network services. The goal was to create a secure, scalable, and high-performance network environment to support business operations.

**Key Tasks and Configurations:**

  • Layer 1 & Layer 2 Switch Configuration: Configured and connected Layer 1 and Layer 2 switches to ensure smooth communication between devices across the network. This included assigning IP addresses, VLANs (Virtual Local Area Networks) for network segmentation, and configuring port security to enhance network safety.
  • Firewall Setup: Implemented a firewall to protect the network from unauthorized access. Configured inbound and outbound traffic rules to prevent vulnerabilities, ensuring only legitimate traffic is allowed while blocking potential threats. The firewall also included configuration for VPNs (Virtual Private Networks) for secure remote access.
  • DHCP Configuration: Set up DHCP (Dynamic Host Configuration Protocol) on the network to automate IP address allocation. This ensured that devices could easily connect to the network without manual configuration, improving efficiency and reducing human errors in IP assignments.
  • Wi-Fi Network Configuration (Unifi Controllers): Deployed Unifi Wi-Fi access points to provide reliable wireless connectivity throughout the organization. Configured Wi-Fi security settings (WPA2 encryption), set up SSIDs (Service Set Identifiers) for different departments, and optimized the network to avoid interference and ensure optimal performance.
  • Card Door System Configuration: Implemented an access control system for physical security. Configured card door systems to control access to specific areas of the office, ensuring that only authorized personnel can enter restricted areas. Integrated the system with the network to enable centralized management.
  • LDAP Configuration: Set up LDAP (Lightweight Directory Access Protocol) for centralized user authentication and directory services. This allowed the network to authenticate users and devices, streamlining the management of user permissions and access control across the network.
  • Windows Server Hosting: Configured Windows-based servers to host critical applications and services. The servers were set up to handle database management, file sharing, and other enterprise-level services. Implemented networked storage solutions and ensured proper server maintenance protocols.
  • Network Monitoring & Optimization: Deployed network monitoring tools to track traffic flow, bandwidth usage, and potential issues. Regularly reviewed network performance and implemented optimizations to ensure uptime and reliability. Troubleshot and resolved any connectivity or performance issues that arose.

This project demonstrated my ability to oversee a comprehensive network deployment, from designing and configuring the physical infrastructure to ensuring optimal performance and security. By integrating these systems, I successfully created a stable, scalable, and secure network that supports the organization's needs while ensuring efficient management and maintenance.
